# Intervenable Audio Scene Graphs: code and result files

Companion material for T-ASL-13354-2026 (revision R1). Everything that
produced the numbers in the paper is here, in the state it was run.

Layout
- `asg/`        the ASG scripts (training, evaluation, revision experiments `p3_r2_*.py`, table generation).
- `physaudio/`  shared single-source physics modules (`p2_common.py`, `p2_train.py`).
- `render/`     the renderer: fractional-delay motion, air absorption, image-source room (`core.py`, `room.py`).
- `paper_gen/`  scripts that write the LaTeX tables and numeric macros from the result files.
- `results/`    every result file (JSON ledgers) behind the tables, including the pre-registered protocol `PROTOCOL_P3.md` with its amendments.
- `listening_test/` the browser test as distributed (open `index.html`, use headphones), the stimuli, `analyze.py`, and the anonymized listener files (`L01` to `L17`; the first submission per listener counts, screening as in `analyze.py`).

Paths
The scripts were run from `/workspace/CF_ASG` with `/workspace/CF_PhysAudio/src` and
`/workspace/audiocf_render` on `sys.path` (see the `sys.path.insert` lines). Recreate that
layout or edit those lines. Checkpoints go to `p3/ckpt/` (see Weights). Rendered scene files
are regenerated by `asg/p3_scenes.py` from FSD50K (dev set; training clips from its train
part, evaluation cohorts from its validation part).

Environment
Python 3.12, torch 2.11.0 (cu128), torchaudio 2.11.0, numpy 1.26.4, scipy 1.17.1,
soundfile 0.14.0, transformers 5.20.1, laion_clap (CLAP metrics), nara_wpe 0.0.11 (WPE
baseline). External systems (AudioSep, FlowSep, SoloAudio, OmniSep, ZETA, Audio-Omni) were
run from their public repositories at the settings stated in the paper; the wrappers are
`asg/p3_x*.py` and `asg/p3_r2_regen.py`.

Weights
`sep3_d3_best.pt` (mask-based separation front end, `p3_sep3.py`), `vel3_v8_best.pt` (speed
estimator, `p3_vel3.py`), `dex_x3_best.pt` (speed-conditioned extractor, `p3_dex.py`), `cls_c2_best.pt` (slot naming head, `p3_cls.py`),
`sep2_latest.pt` (slot network whose existence and environment heads are used),
`est2_latest.pt` (earlier speed head) and `est_latest.pt` (environment and absorption heads) are
release assets of this repository.

Reproducing the revision tables
0. The deployed system is configured through the environment: `SEP3_CKPT=sep3_d3_best.pt
   VEL3_CKPT=vel3_v8_best.pt ALPHA_SEL=kurtj DEX_CKPT=dex_x3_best.pt DEX_GATE="K>1&agree<10" SLOT_NAMING=cls CLS_CKPT=cls_c2_best.pt`
   for `asg/p3_r2_run.py`, and the flags `--sep3 sep3_d3_best.pt --vel3 vel3_v8_best.pt
   --alpha_sel kurtj --dex dex_x3_best.pt --dex_gate "K>1&agree<10" --slot_naming cls --cls_ckpt cls_c2_best.pt` for `asg/p3_edit_eval.py`
   (`asg/p3_phiB.py evalref -- <same flags> --split mmB` for the physics-mismatch cohort).
   Training: `asg/p3_sep3.py train` (then `--init` continuations with `--dm 1`), `asg/p3_vel3.py
   cache` and `train`, `asg/p3_dex.py train --loss snr`.
1. `asg/p3_r2_run.py --system ours|x1|x2|x3|x4` and `asg/p3_r2_regen.py --system x5|x6` replay
   the pre-registered edit specs and save every edited waveform.
2. `asg/p3_r2_metrics.py --system <s>` scores CLAP, RT60 and EDC; `asg/p3_r2_verdict.py` and
   `asg/p3_r2_main_table.py` aggregate; `paper_gen/gen_tables_r2.py` writes the tables.
3. `asg/p3_r2_wpe_baseline.py` is the WPE baseline, `asg/p3_r2_confirm_k2.py` the confirmation
   cohort under the two-source rule, `asg/p3_r2_listening_ci.py` the listening intervals.
